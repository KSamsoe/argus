# argus-assets: spec trace

Every statement in the design document (v0.3) that constrains the asset importer as phase 1 item 4 scopes it (§14 "Assets", §4 `.argus/` is a cache, §8 events, §18 phase 1), with where it lives and the test that pins it. Statuses as in the other traces: **Done**, **Partial**, **Deferred**.

## §14 Assets

| Spec | Status | Where | Test |
|---|---|---|---|
| Source assets live in `assets/` and are described by sidecar TOML files that the agent can write. | Done | An asset's name is its path under `assets/` without the extension; its sidecar is `<name>.toml` beside it (`<name>.atlas.toml` from item 1 still works). A PNG is a sprite, a WAV is a sound, a sidecar alone is whichever its keys or `type` say. Two sources for one name, or a sidecar that describes nothing, is an error naming the file. | `importer::bad_sidecars_fail_with_the_line_and_the_rest_still_import` |
| A sprite sheet's frames and pivots. | Done | `sidecar.rs`: `grid = [cols, rows]` or `[[frames]] rect = [x, y, w, h]`; `pivot` (a fraction of the frame, y up, so `[0.5, 0.0]` is the feet) as a default and per frame; `pixels_per_unit`. The renderer puts the pivot on the entity's position and mirrors it with `flip_x`. | `importer::a_placeholder_is_replaced_by_the_art_under_the_same_name`, `argus-render/tests/render.rs::a_placeholder_asset_draws_with_its_pivot_and_the_art_replaces_it` |
| An animation's clip list and rates. | Done | `[clips.name] frames = [...]` or `from`/`to`, `fps` or per-frame `duration_ms`, `loop`, `direction` (forward, reverse, pingpong). Item 8's animator plays them. | `importer::the_sidecar_carries_what_aseprite_and_tiled_carry` |
| An audio file's gain and variation set. | Done | A sound sidecar is one `[sounds."name"]` table of `audio.toml` (`argus_audio::parse_sound_sidecar`): bus, gain, jitter, `variations` (files relative to the sidecar's folder, or tones), `max_voices`. A sidecar beside a WAV plays that WAV. The mixer loads sidecar sounds below `audio.toml` and above bare WAVs. | `importer::a_sound_sidecar_names_its_variations_and_the_files_are_checked`, `argus-daemon/tests/assets.rs` |
| The importer watches the tree. | Done | `Importer::poll` reads each file's metadata under `assets/` and scans only when something changed; an unchanged asset is not re-read. The daemon polls twice a second and before `obs.frame`, and `asset.import` scans on demand. A changed sprite reloads in every renderer; a changed sound reloads in the mixer, whose playing voices keep their old samples. A variation WAV that changes re-imports the sound that plays it. | `importer::a_placeholder_is_replaced_by_the_art_under_the_same_name`, `argus-daemon/tests/assets.rs::assets_import_on_open_report_as_events_and_hot_swap` |
| Produces a cache in `.argus/`. | Done | `.argus/assets/<name>.png`: the texture the renderer loads (padded to powers of two, or the drawn placeholder), and `.argus/assets/manifest.json` with every entry and failure. A removed asset's cached texture is deleted. `.argus/` is gitignored (§4). | same |
| Reports every import as an event with warnings ("frame 7 is empty", "texture not power-of-two, padding"). | Done | Warnings, each with `file:line` or the file: `frame N is empty`; `texture WxH is not power-of-two, padding to W2xH2`; a grid that does not divide the image; a pivot outside the frame (clamped); a clip naming a frame that does not exist (dropped); unknown keys; shape keys beside a real PNG (`kind, size, and color are ignored: assets/x.png is the art now`); for sounds, more than one channel, a rate other than the mixer's, a file that clips, a silent file, a long effect outside `music/`. In the log: `assets.scanned` when a scene opens, then `asset.imported {asset, kind, warnings}`, `asset.warning {asset, at, message}`, `asset.failed {asset, at, message}`, and `asset.removed {asset}`. One bad asset never stops the rest. | all four importer tests; `argus-daemon/tests/assets.rs` |
| Aseprite and Tiled files import natively with their internal structure exposed through the sidecar. | Partial | The sidecar already holds their structure: per-frame durations and tags as clips with a direction (Aseprite), per-frame properties (Tiled tiles). Reading `.aseprite` and `.tmx` files directly is phase 5, as the plan lists; those importers will fill these same fields. | `importer::the_sidecar_carries_what_aseprite_and_tiled_carry` |
| A tileset's auto-tiling rules and tile properties (§12 "Tilemaps", item 5). | Done | A tileset is a sprite asset. `[autotile.<terrain>]` in its sidecar has `mode` (`single`, `4bit`, `blob47`), `tiles` (1, 16, or 47 tile ids, where tile `n` is frame `n - 1`), and `edges` (`connect` or `open`); the import checks the count for the mode and that every id is a frame of the sheet. `SpriteAsset::tile_property(tile, key)` reads a tile's frame properties (`solid`, `one_way`) for collision. `argus-tiles` reads both. | `argus-tiles/tests/tiles.rs::four_bit_auto_tiling_picks_each_tile_from_its_neighbours` |
| An animator's state machine (§13, item 8). | Done | A sidecar with `type = "animator"` (or `[states.*]`/`initial`) is an asset of kind `animator`: `animator.rs` parses states (clip, loop, fps, windup, anticipation, hold, hold_frame, events), transitions (to, when, window, blend), and `[[any]]`, and checks every condition's syntax and every state name. Mistakes fail the import with `file:line`; unknown keys are warnings. `Importer::animators` lists them; `asset.get` shows states, events, and transitions. | `importer::an_animator_imports_with_its_states_and_its_mistakes_have_lines` |
| A material (§13, item 11). | Done | `<name>.wgsl`, with a sidecar of typed parameters (`type = "material"`, or `shader`, `params`, or `blend`), or a sidecar naming a library material's shader to vary its defaults. `argus-material` reads it and checks the composed shader with naga at import, so a compile error fails the import with the `.wgsl`'s own line. A `.wgsl` beside a `.png` or `.wav` of the same name is ambiguous. `Importer::materials` lists the project's and the library's; `material_json` is what `asset.get` shows. A particle effect may name a material (`material`). | `importer::a_material_imports_checked_and_its_shader_errors_have_lines` |
| A particle effect (§13, item 10). | Done | A sidecar with `type = "emitter"` (or `rate`, `burst`, or `lifetime`) is an asset of kind `emitter`: `effect.rs` reads the shape, rate, burst, duration, max, lifetime and speed ranges, direction, spread, gravity, drag, space, z, and the curves over life (velocity, size, rotation, colour) as control-point lists, and checks the ranges, the colours, and that each curve's t runs from 0 to 1 and never back. Mistakes fail the import with `file:line`; unknown keys are warnings. `Importer::emitters` lists them; `argus-particles` runs them. | `importer::an_emitter_imports_with_its_curves_and_its_mistakes_have_lines` |
| A tile's slope (§12, item 6). | Done | `slope = [left, right]` in a frame's properties, heights from 0 to 1; `parse_slope` reads it; anything else is a warning naming the frame's line, and the tile is solid. | `argus-tiles/tests/tiles.rs::the_store_reads_slopes_and_notices_a_map_saved_elsewhere` |
| Generated art drops into the same tree and gets the same treatment. | Done | There is no other path: any PNG under `assets/` is imported the same way. | |
| A placeholder sprite as a described shape (`kind = "rect"`, `size = [8, 8]`, `color = "#E8703F"`) so gameplay work never waits on art, and the human replaces the file later without touching a reference. | Done | A sidecar with no image and `kind`/`size`/`color` is drawn by the importer into the cache as a real texture, so it is an asset like any other. When `<name>.png` appears the same name imports as the art; the entity's `Sprite.atlas` never changes. Both example games' heroes are such placeholders. | `importer::a_placeholder_is_replaced_by_the_art_under_the_same_name`, `argus-render/tests/render.rs::a_placeholder_asset_draws_with_its_pivot_and_the_art_replaces_it`, `argus-daemon/tests/assets.rs` |

## §5 Protocol

| Spec | Status | Where | Test |
|---|---|---|---|
| Assets are queried, not read (P2). | Done | `asset.list {kind}` (paged rows: name, kind, source, frames, clips, warnings, plus failures), `asset.get {name}` (every frame, clip, file, and warning), `asset.import {force}`. `asset.move` rescans after a rename. `session.open` reports asset totals. | `argus-daemon/tests/assets.rs` |

## Phase 2, item 7: the import cache in a release pack

| Spec | Status | Where | Test |
|---|---|---|---|
| (§15) A release pack is built from the import cache, not the source tree. | Done | `catalog.rs`: `Importer::packed_sprites` gives each sprite's cached texture and what the importer made of it (frames, pivots, properties, clips, auto-tiling, the placeholder shape) as `argus.cache/catalog.json`, and names the source images and sprite sidecars a pack leaves out. `Importer::packed(root)` loads a mounted pack's sprites from the catalog; a scan then imports the rest (sounds, animators, emitters, materials) from their sidecars and neither imports nor drops the catalog's sprites. | `argus-player/tests/packs.rs` |

## Phase 3, item 1: fonts

| Spec | Status | Where | Test |
|---|---|---|---|
| (§12) SDF text with shaping: a font is an asset. | Done | `font.rs`: a `.ttf` or `.otf` under `assets/` imports as a signed distance field atlas (32 pixels an em, a 4-pixel reach, by default; a sidecar may set `size`, `spread`, and `chars`), baked from the glyph outlines: printable ASCII, Latin-1, common punctuation, the sidecar's characters, and whatever the font's substitutions make of them (ligatures, alternates). The font's bytes are kept for shaping. A character the font lacks is a warning. A process bakes a font once for the same inputs, so a test run that loads the project 57 times does not bake it 57 times. In a release pack the font file ships as it is and imports at start. | `importer::a_font_imports_as_a_distance_field_atlas_of_the_glyphs_text_needs` |

## Known limitations, stated so they are decisions

- The watcher polls file metadata twice a second rather than using OS notifications. It is deterministic, has no dependency, and costs one metadata read per file.
- A daemon start re-imports every asset: the cache is written for the renderer, but the manifest is not read back to skip work. Fine at example scale; reading the manifest is the change when a project's asset count makes the cold open slow.
- PNG and WAV only, and TrueType and OpenType fonts (not collections). Other image and audio formats, and the native Aseprite and Tiled readers, come later.
- A font imports in about 0.3 s in a debug build (Liberation Sans, 208 glyphs, a 472 x 388 atlas); it is not written to the cache, so a daemon start bakes it again.
- Placeholder shapes are drawn with hard edges at their pixel size; the renderer's nearest-neighbour magnification keeps them crisp.
