2D game engine0.2.0, free and open source

You and an AI, building one game together.

Argus is a 2D game engine made so an AI agent can work on a game as well as you can, right beside you. The game runs live, and you, the agent, the tests and the command line all work on that one running game.

01The idea

Most game engines seat one person at an editor. Argus seats two.

You

At the editor, with the live game in front of you.

One live gameThe tests and the command line use it too.

The agent

In Claude, Cursor or Codex, on the same running game.

The game runs live in a background program that holds its whole world. Everyone works on that world through one protocol, so the agent works from the game itself. It can look at the game, play it, rewind it, test it and change it, then tell you what happened and why.

        04Every change is a step
        
    
        
      
        
        
        Every change is a step you can see and undo.
        
        
        Edits are transactions. Each one carries a note and an author, you or the agent, and they all land in one change feed. You can see who changed what and why, and undo any step.

        05Same seed, same game
        
    
        
      
        
        
        The same seed plays the same game, bit for bit.
        
        
        A run comes out the same on Windows, Linux, the Mac and in the browser. A failing test saves a replay that opens at the moment it failed. When a player flags a moment while playing, with a mark and a note, the agent opens the game at exactly that frame. It is also what lets players play together online: every machine computes the same world from everyone's input.

        07Tuning and speed
        
    
        
      
        
        
        Tuning and speed are data too.
        
        
        Mark a field as tunable and sweep it across seeds. profile reports each system's cost against the game's performance targets, and names the system to look at.
        
        
        
          
        Systems run in parallel
        
          
        1 thread6.7 ms
        
          
        4 threads2.0 ms
        
          
        Four heavy systems, one tick. Systems that do not touch the same components run side by side, and the world comes out identical on 1, 3 or 4 threads.

        12Get started
        
    
        
      
        
        
        Start from a game that already plays.
        
        
        Argus is free and open source, on Windows, Linux and the Mac. Install it with one command. A new game starts from a template: a small game that already plays, with its art drawn by a script you or an agent can change, and scenarios that pin how it plays.
        
        
        
          
        Install
        
          
          
            
        • irm https://argusengine.org/install.ps1 | iexWindows, in PowerShell
          • 
            
        • curl -fsSL https://argusengine.org/install.sh | shLinux or macOS, in a terminal
          • 
          
        
        
        
        
        Then open a new terminal. The install guide says what a machine needs and how to connect each AI tool.
        
        
        
          
        Five commands
        
          
          
            
        1. argus new my-game --template platformeror blank, roguelike, arena, colony
          2. 
            
        2. cd my-gameinto the new project
          3. 
            
        3. argus testthe template's scenarios pass
          4. 
            
        4. argus editorthe game in the editor
          5. 
            
        5. argus mcp setup claude-codeor claude-desktop, cursor, vscode, codex, gemini
          6. 
          
        
        
        
      
        
      
    
        
  
        

        



        
  
        
    
        13Where it stands
        
    
        Plainly, where Argus is today.
        
    
          
      
        • YoungArgus is at version 0.2.0, its first public release. Expect rough edges, and say so in an issue when you find one.
          • 
      
        • 2D onlyThere is no 3D.
          • 
      
        • Phones play in the browserPhones and tablets play Argus games in the browser, not as installed apps.
          • 
      
        • Online needs a relayPlayers connect through a relay, which you run yourself, and a match ends if a player's connection drops.
