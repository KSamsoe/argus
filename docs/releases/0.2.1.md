# Argus 0.2.1

0.2.1 fixes one thing in the relay. Nothing else changed, and a game made on 0.2.0 needs no change.

## Fixed

- **A web page hosting a room was dropped after 30 seconds if no one joined.** The relay drops a player it hears nothing from for 30 seconds. A desktop game pings it, but a browser sends no pings of its own, so a page waiting alone for a friend fell silent and lost its room before the friend could type the code. The relay now pings every player every 10 seconds. A page or a game answers on its own, so a host can wait as long as it likes, and a player who has really gone still answers nothing and is dropped. Only the relay changed: a relay started with `argus relay` from 0.2.1 keeps web hosts, whichever version their game was built with.

## Install

`irm https://argusengine.org/install.ps1 | iex` on Windows, or `curl -fsSL https://argusengine.org/install.sh | sh` on Linux and macOS, which are this release's `install.ps1` and `install.sh`; see [docs/install.md](https://github.com/KSamsoe/argus/blob/v0.2.1/docs/install.md). An install from 0.2.0 or 0.1.x updates with `argus self-update`. The macOS build is cross-built on Linux and universal (Apple Silicon and Intel); [docs/mac-testing.md](https://github.com/KSamsoe/argus/blob/v0.2.1/docs/mac-testing.md) is the packet for checking it on a Mac, with `mac-expected.json`. To play the example games with nothing installed, there's `example-games-0.2.1` for Windows, Linux, or macOS; each archive's `README.txt` has the controls.
