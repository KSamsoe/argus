# Argus 0.1.0

0.1.0 is the first release with a whole game made on Argus. Bring Your Own Game Master, a game whose story an AI game master runs, was built on the engine from start to finish, and with this release every issue its making turned up is closed. It is also the release that adds the staples a 2D game reaches for: raycasts and shape queries, capsule and polygon colliders, parallax, debug drawing, save slots, and turn-based games that keep animating between turns.

**What the version means from here.** Until now every release could change anything. From 0.1.0 on, a 0.1.x release fixes and adds without breaking a game made on 0.1.0. A change that would break one waits for 0.2.0 and is listed under "Breaking changes" in that release's notes, with what to do. This release's breaking changes, from 0.0.8, are [below](#breaking-changes-from-008).

## New: the 2D staples

- **Raycasts and shape queries.** `q:raycast(from, to)` gives the first thing a line meets (the entity or tile cell, the point, the surface's normal, the distance); `q:raycast_all` gives every hit, nearest first. `q:shape_cast` moves a shape (a circle, box, capsule, or convex polygon) along a line and says where it stops, and `q:overlap` lists everything a shape placed at a point touches. They meet every `Collider` (filtered by layer) and tilemaps' collision cells, slopes and one-way platforms included. The math is exact and the same on every platform. ([Gameplay](https://github.com/KSamsoe/argus/blob/v0.1.0/docs/manual/gameplay.md))
- **Capsule and polygon colliders.** A `Collider` can be a capsule (`radius` and `height`) or a convex polygon (`points`) as well as a box or a circle. Overlaps, rigid bodies, and the queries all meet the real shape; a kinematic body still moves as the box around it.
- **Parallax.** A `Parallax` on a sprite (`factor`, `origin`) draws it slower or faster than the world as the camera moves, and a tile layer takes `parallax` in its map file. Tiled maps' parallax factors are imported instead of dropped. It is drawing only: collisions stay where things are. ([Presentation](https://github.com/KSamsoe/argus/blob/v0.1.0/docs/manual/presentation.md))
- **Debug drawing.** `q:draw_line`, `q:draw_arrow`, `q:draw_box`, `q:draw_circle`, and `q:draw_text` draw in world space until the system runs again. They show in the window, the editor, and `obs.frame`'s pictures, are listed in the semantic frame's `debug`, and never appear in a release build.
- **Save slots.** `q:saves()` lists the saves there are, newest first, with when each was made, its scene, and a summary the game chose (`q:save(name, summary)`); `q:delete_save(name)` deletes one. That is enough for a Continue button or a three-slot menu. The list a tick read is recorded with the input, so a replay, a seek, or a report reads the same list.
- **Animation between turns.** In a turn-based game, animators, particles, tweens, the camera, skeletons, timelines, and post effects now move while the game waits for the next turn, instead of only on turns. That time is part of the run: it is recorded with the input, so replays, seeks, and reports match. A script's own system joins in with `between_turns = true`; `sim.idle` and a scenario's `t:idle(seconds)` run idle time on purpose.

The example games use each one: Toybox has a wedge (a polygon), a pill (a capsule), and a tripwire laser (a raycast, debug-drawn). Hollow's back wall is a parallax layer at half speed. In Delve, monsters see the hero only along a clear line (a raycast per monster, with a debug view of the sight lines), the menu has three save slots, and sparks fly between turns.

## Fixed: from Bring Your Own Game Master's last stretch

- **A script that does not load is named first** (#30), in `argus summary`, the daemon's status, and when the project opens. The systems ordered after it still run, unordered, and the order report says which script they were waiting on and why it failed.
- **UI laid out off the screen is named** (#31). A node that comes out past its parent or the canvas (a row of buttons too wide for the screen, say) is listed under `ui_overflow` in `argus summary` and under `problems` in the semantic frame, buttons and text boxes first.
- **Scrolling panels** (#32) cut their contents inside their padding, so a border is never drawn over, and `UiScroll.to = <child>` scrolls a line into view. The presentation chapter now covers how a scrolling node is sized, how its scroll is kept in range, the mouse wheel, and what the semantic frame lists.
- **Mouse bindings with modifiers** (#33). `mouse = ["ctrl+left"]` is an action of its own (`ctrl`, `shift`, `alt`, `meta`). While it is pressed, a plain `left` stands down, and Ctrl needs no binding, so in a turn-based game holding it takes no turn. A web page's input calls (`player.key`, `mouse`, `pointer`, `wheel`, `text`) are documented.
- **Queries agree** (#34). A web page's `player.query` now includes switched-off entities, as the protocol's `world.query` does, and a `!` name leaves them out. `world.query`'s row order is documented, and `"order": "ref"` sorts rows by how the protocol names them, named entities first by name, so a scenario or tool that draws from the rows does not depend on the order the entities were made in.
- **Smaller gaps** (#35). `argus docs --for-agent` stops a daemon it had to start. `asset.import` says what the watcher imported as files were saved (`imported_since`). `asset.preview` takes a `path`. The semantic frame marks a text it cut short (`cut`). The testing, content, and reference chapters answer the questions that cost probes.
- **The platformer template works again.** The engine's new `Parallax` took the name of the platformer template's own backdrop component, so a new platformer project had script errors. The template's component is now `Backdrop`.

## Breaking changes from 0.0.8

- **`Parallax` is now the engine's.** A game that declared its own component named `Parallax` gets a script error that says the name is taken, and every project made from 0.0.8's platformer template has one. Rename yours: in a platformer project, change `Parallax` to `Backdrop` in `components/looks.luau`, in `systems/looks.luau` (its `q:each`, `reads`, and `writes`), and in the `[Parallax]` tables of `scenes/level/clouds.toml`, `hills.far.toml`, and `hills.near.toml`.
- **`player.query` includes switched-off entities.** A page script that relied on it leaving them out adds `!Inactive,!InactiveUnder`: `player.query("Monster,!Inactive,!InactiveUnder")` is what a script's `q:each("Monster")` sees.
- **A scrolling panel with padding shows a little less.** It now cuts at the inside of its padding, so a picture golden of one may need recording again (`argus test --update`).
- **Some recordings made on 0.0.8 will not end on the same world.** In a turn-based game, what animates between turns now takes no time on a turn; it moves on the idle time instead. And two rigid-body fixes change contacts: rigid bodies now meet a kinematic body with a circle collider at the circle's box, not at its unused `size`, and a collider whose shape changes in place takes the new shape at once. Record replays, reports, and goldens of such games again.
- Saves from 0.0.8 still load: a component that gained fields (`Collider`'s `height` and `points`) gives them their defaults.

## Install

`install.ps1` (Windows) or `install.sh` (Linux and macOS), from the archive or with a GitHub token from this release; see [docs/install.md](https://github.com/KSamsoe/argus/blob/v0.1.0/docs/install.md). An install from 0.0.8 updates with `argus self-update`. The macOS build is cross-built on Linux and universal (Apple Silicon and Intel); [docs/mac-testing.md](https://github.com/KSamsoe/argus/blob/v0.1.0/docs/mac-testing.md) is the packet for checking it on a Mac, with `mac-expected.json`. To play the example games with nothing installed: `example-games-0.1.0` for Windows, Linux, or macOS (its `README.txt` has the controls; the Mac's has no Swarm, whose Rust plugin is built on a Mac).
