# Argus 0.1.2

0.1.2 is a fix for turn-based games. A player's report, and a mark, now reach back by turns, however long the player spent scrolling or typing before flagging the moment. Nothing in it breaks a game made on 0.1.0 or 0.1.1.

## Fixed

- **A report on a turn-based game could miss the turn it was about** (#36). In a turn-based game, every mouse-wheel notch, typed character, and menu press runs a tick of its own that takes no turn. A report's window counted those ticks. So a player who read back through a log with the wheel, or typed a long line, before pressing F8 pushed the turn they meant out of the report. Bring Your Own Game Master's report of a ruling covered 45 ticks of scrolling and none of the turn. The window now counts turns:
  - **Reports** from a release build or the web page reach back 30 to 60 turns. While the player scrolls or types with no turn passing, a report still takes a fresh starting point every 3,000 ticks, so its memory stays bounded.
  - **Marks** in the editor or the playtest window reach back ten turns.

## Install

`install.ps1` (Windows) or `install.sh` (Linux and macOS), from the archive or with a GitHub token from this release; see [docs/install.md](https://github.com/KSamsoe/argus/blob/v0.1.2/docs/install.md). An install from 0.1.0 or 0.1.1 updates with `argus self-update`. The macOS build is cross-built on Linux and universal (Apple Silicon and Intel); [docs/mac-testing.md](https://github.com/KSamsoe/argus/blob/v0.1.2/docs/mac-testing.md) is the packet for checking it on a Mac, with `mac-expected.json`. To play the example games with nothing installed, there's `example-games-0.1.2` for Windows, Linux, or macOS; each archive's `README.txt` has the controls.
